# BabyBaby Guides calendar and drafts

The [guide calendar](calendar.json) sets the weekly publication dates. Codex researches and writes the next guide while Eric's computer is on, then commits its complete HTML file to `editorial/drafts/<slug>.html`. A draft is a publishing to-do: it is not added to the public guides listing or sitemap until its calendar date.

GitHub Actions runs the publisher at 10:17 Europe/Berlin every day and whenever a draft or calendar change is pushed. It publishes the earliest due, unpublished slot only if a complete draft exists. A daily check catches up if a scheduled run is delayed or missed. If the computer is off, a draft already on GitHub can still publish; GitHub cannot research or write an unwritten guide. No API key is used.

For each draft, answer a specific parenting question with useful, original advice. Research current primary sources, link them near the claims they support, and use at least two independent authoritative organizations. Avoid diagnosis, invented facts, guilt, and product pitches. Mention a verified BabyBaby feature only when it helps the reader. Use a real screenshot when it clarifies a feature, with accurate alt text and a sample-data caption. Check dates, links, accessibility, mobile layout, metadata, and the site's existing guide style before committing. Keep at least the next weekly draft ready; add future calendar slots before the schedule runs out.

The workflow validates the draft, creates the guide page, updates the guides index and sitemap, mirrors those files in `dist/`, requests the existing GitHub Pages build, and checks the live URL. Missing drafts or failed checks stop publication and show an error in the Actions run. To rerun a due slot, use **Run workflow** with no slug. Supplying a calendar slug publishes it immediately, even before its date; use that option only for an intentional early release. A guide already published will not be duplicated.

The automated checks verify structure and source provenance, but cannot guarantee that every interpretation of a medical or developmental source is correct. If current guidance cannot be verified, hold the draft and explain the issue rather than publish unsupported advice.
