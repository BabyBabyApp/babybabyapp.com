# BabyBaby website

Static, film-led homepage for babybabyapp.com. Root HTML/CSS/JS and media preserve the existing GitHub Pages layout. `dist/` contains the same authored assets for the private Sites review. Keep both copies in sync when editing. Legal pages and CNAME are retained.

The main film is `media/babybaby-film.mp4` with matching English WebVTT captions. Playback begins muted when the browser allows it and respects reduced-motion and data-saving preferences. Native video controls and a visible sound/replay button work without a custom player. A transcript is also available.

Before publishing, validate the four HTML pages and their local links/assets, check JavaScript syntax with `node --check site.js`, and ensure the preview returns HTTP 200. No framework or package installation is required.
